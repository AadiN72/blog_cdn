I have been circling the idea of writing a ray tracer for a while, and the F# version of the classic book was the first time the concept felt both approachable and elegant.

The book does something smart: it teaches the math and the structure of the renderer without turning the whole project into a giant black box. You build the scene, the geometry, the shading, and then slowly watch the image emerge from the code.

F# adds a nice layer of clarity here. The type system, pattern matching, and immutable style make the geometry code feel surprisingly calm. It is a good reminder that writing graphics code is not only about performance; it is also about precision and composability.

I am still not finished with my version, but I am convinced the right project is the one that teaches you how to think.
