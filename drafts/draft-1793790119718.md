This weeks lesson is on git in general. Git and Github has beecome the one of if not the most ubiquitous tools used in programming and development. Before i talk more about it it like to regale the story of how and why git was made becuase i found it really interesting.

## The tale of git

When linus torvaldis was building Linux he had issues where he couldnt resolve the indenpendent work of other collaborators of linux with his work locally.

To resolve this he made git a collaborative system where people can resolve their work make commits to save their work and make and merge pull requests to work together optimally

I find it fascinating that linus had both the skills and time to pause his main project and make a side project in a time without AI
